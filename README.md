# Modern Music Player 🎵

A sleek, modern, and fully responsive music player built using **Vanilla HTML, CSS, and JavaScript**. Designed and developed as part of a personal web development portfolio.

## ✨ Features

- **Play / Pause Controls:** Smooth audio playback toggle with dynamic icon changes.
- **Playlist Support:** Interactive playlist where users can click and switch between multiple tracks.
- **Progress & Seek Bar:** Real-time track progression update and click-to-seek functionality.
- **Dynamic Track Info:** Automatically updates song titles, artist names, and album cover art.
- **Modern Glassmorphism UI:** Clean dark-theme aesthetic with smooth CSS backdrop filters and animations.

## 🛠️ Tech Stack

- **HTML5:** Semantic structure and built-in `<audio>` API.
- **CSS3:** Custom styling, Flexbox, glassmorphism design, and responsive layout.
- **JavaScript (ES6+):** DOM manipulation, event listeners, and playlist state management.
